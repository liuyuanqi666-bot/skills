# 固定护照模板参数

## 资源与隐私

- 权威模板：`../assets/passport-template.xlsx`
- 模板来源：用户提供的“游客名单（测试）.xlsx”，已清除第 2 行起的全部真实人员数据。
- 每次直接使用内置模板；用户无需再次上传模板。
- 不得把后续源报表中的姓名、护照号或出生日期保存进技能目录。

## 工作簿结构

| 参数 | 固定值 |
| --- | --- |
| 工作表 | `sheet1` |
| 模板工作表维度 | `A1:H19` |
| 护照数据核心区域 | `A:H` |
| 表头行 | 第 1 行，可见 |
| 领队行 | 第 2 行，表头下方第一行 |
| 游客起始行 | 第 3 行 |
| 合并单元格 | 无 |
| 冻结窗格 | 无 |
| 自动筛选 | 无 |
| 公式 | 无 |
| 网格线 | 显示 |

## 字段与类型

| 列 | 标题 | 数据类型 | 规则 |
| --- | --- | --- | --- |
| A | 中文姓名 | 文本 | 保留源值；领队使用已确认中文名 |
| B | 姓 | 文本 | 英文大写 |
| C | 名 | 文本 | 英文大写 |
| D | 出生日期 | 数值 | `YYYYMMDD` |
| E | 性别 | 文本 | `M` 或 `F` |
| F | 国籍 | 数值 | 中国 112；印度尼西亚 125；越南 185；菲律宾 155 |
| G | 护照号码 | 文本 | 英文大写，保留前导零 |
| H | 护照有效期 | 数值 | `YYYYMMDD` |

## 列宽

以下为 Excel 中显示的列宽：

| 列 | 宽度 |
| --- | ---: |
| A | 8.55 |
| B | 10.64 |
| C | 13.73 |
| D | 13.09 |
| E | 7.91 |
| F | 7.91 |
| G | 13.09 |
| H | 21.64 |

不得自动适应列宽。I:P 不属于护照数据区域，必须保持无内容、无身份信息。

## 行高与样式

| 行 | Excel 行高 | 用途 |
| --- | ---: | --- |
| 1 | 28 | 可见表头 |
| 2 | 23.2 | 领队数据行 |
| 3 及以后 | 12.5 | 游客数据行；姓名换行时允许按模板显示 |

- 第 1 行 A:H：10 号模板字体，蓝色文字，自动换行，水平居中，四周细边框。
- 数据行：Arial Unicode MS，10 号，自动换行，四周黑色细边框。
- A、B、C、E、G 写入文本；D、F、H 写入数值。
- 不要对列宽执行自动适应，不要全表自动行高。
- 超过模板预留行时，使用第 3 行样式扩展并确保新增行保留完整边框。

## 标题值与批注

第 1 行实际值依次为：

```text
中文姓名 | 姓 | 名 | 出生日期 | 性别 | 国籍 | 护照号码 | 护照有效期
```

保留以下批注：

- D1：`YYYYMMDD`
- E1：`男 : M`、`女 : F`
- F1：`CHINA P. R. : 112`、`INDONESIA : 125`、`VIETNAM : 185`、`PHILIPPINES : 155`
- H1：`YYYYMMDD`

## 页面与打印

| 参数 | 固定值 |
| --- | --- |
| 纸张 | A4（paperSize 9） |
| 方向 | portrait |
| 缩放 | 100% |
| 水平/垂直 DPI | 600 / 600 |
| 左/右边距 | 0.7 / 0.7 英寸 |
| 上/下边距 | 0.75 / 0.75 英寸 |
| 页眉/页脚边距 | 0.3 / 0.3 英寸 |

## 输出命名

- 默认：`0领队{领队中文姓名}.xlsx`
- 缺少领队姓名时必须询问，不得根据第一位游客推断。
