# 分房业务规则

## 规则优先级

按以下顺序处理，前项高于后项：

1. 未成年人安全、同性单拼、人员不可遗漏或重复等硬性规则。
2. 客人明确且无歧义的备注。
3. 用户在对话中的最新确认。
4. 同订单家庭优先在一起。
5. 默认两人一间。
6. 客人之间优先单拼，最后再考虑领队。

备注不能覆盖未成年人禁止单拼和跨订单只能同性拼房等硬性规则。备注与硬性规则冲突时停止并询问用户。

## 基础定义

- 同一订单号视为一家人。
- 年龄以团队出发日期计算；出发当天未满 18 周岁为未成年人。
- “单拼”指不同订单人员共住一间房。
- “单住”“不拼”“已补房差”“房差已补齐”等明确语义指单独一间，不进入单拼池。
- “男拼”“女拼”指抽出对应性别的合格成年人进入单拼池。
- 领队不属于任何游客订单。
- 单拼只允许同性成年人。

## 默认分房

- 默认两人一间。
- 同订单人数为偶数时，优先保持家庭连续，按源表顺序每两人一间；除非备注或用户明确指定其他搭配。
- 同订单人数为三人，且备注明确“三人一间”时，安排一间三人房；模板房型可按用户要求继续填写“标间”。
- 类似“五人两间”的明确备注，通常按 3+2 安排；若备注没有明确三人房、加床或房型，先询问。
- 备注明确单数人员单独一间且已补齐房差时，安排单人房，不进入单拼名单。

## 单数家庭

1. 先读取备注是否明确“男拼”或“女拼”。
2. 只能抽出对应性别、出发时已满 18 周岁的成员。
3. 有多名符合条件的成年人且备注未点名时，停止并询问用户抽出谁。
4. 没有符合条件的成年人时，停止并询问。
5. 抽出的家庭成员进入同性单拼池；家庭其余成员仍优先同住。
6. 若外部只剩一名女拼，家庭拆出人员必须为女性；男性同理。

## 单人订单

- 单人订单中的成年人进入相应性别的单拼池。
- 单人订单中的未成年人不能单拼，必须停止并询问用户。
- 两名同性成年单拼游客可配成一间。
- 仅剩一名无法匹配的客人时，不得擅自异性拼房；按用户确认决定单住或调整其他家庭。

## 领队

- 用户明确确认本团无领队或导游时，不创建领队人员、不进入拼房池、不生成 `TL` 行；顶部“领队：”栏仍保留为空，人数使用“游客数+0”。
- 领队在客人单拼全部处理后再进入同性单拼池。
- 领队只能与剩余的同性成年游客拼房。
- 没有合适的同性成年游客时，领队单开一间。
- 领队永远位于表格最后；与领队拼房的人紧邻领队并排在其前。
- 若从家庭拆出一人与领队拼房，将该家庭整块移动到名单末尾；保持家庭成员连续、备注编号清晰，最后一行仍为领队。
- 不得从姓名推断领队性别。

## 输出顺序与备注列

- 同订单家庭在表格中连续排列。
- 备注列使用连续数字标记同订单家庭，并纵向合并覆盖该家庭的所有游客。
- 备注列不直接复制源表的业务备注。
- 单人订单通常不需要家庭编号。
- 领队不纳入任何家庭编号，备注合并范围不得包含领队。
- 房号按 1、2、3……连续排列。
- 每个房间的“房号”和“房型”纵向合并；单人房无需额外合并。

## 必须暂停询问的典型情况

- “单”无法判断是单住还是单拼。
- “女单/男单”无法判断是单住还是女拼/男拼。
- 备注只写“五人两间”，但无法确定是否允许三人房或加床。
- 单数家庭没有明确抽出人员，且存在多个合格候选人。
- 要求拆出的唯一人员为未成年人。
- 单拼池仅剩异性人员。
- 有领队但领队性别或电话缺失；用户明确确认无领队或导游时不属于缺项。
- 出发日期不明，无法判断是否成年。
- 订单号缺失，无法判断家庭关系。
- 名单总人数与“人数”字段不一致。
- 同一人员在不同来源中的姓名、性别、生日、护照号或有效期冲突。
