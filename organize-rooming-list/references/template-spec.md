# 分房名单模板规范

## 工作表结构

默认工作表名为 `Sheet1`，主要区域为 A:N。

- A1:C3：合并标题，格式为 `分房名单` 换行 `档XX`。
- D1：`团号：`
- E1：团号。
- F1:K1：行程名称。
- L1：有领队时为 `领队：姓名`；明确无领队或导游时保留 `领队：`，姓名留空。
- M1:N1：`人数：游客数+领队数`
- D2：`航班信息：`
- E2:N2：航班信息。
- D3：`用房数量：`
- E3:N3：实际用房数量及必要说明。
- 第 4 行为表头。
- 第 5 行开始为人员数据。

## 航班信息固定写法

默认写作：`{去程航班号} {出发地简称}→{目的地简称} （{起飞时间}-{到达时间}）；{返程航班号} {出发地简称}→{目的地简称} （{起飞时间}-{到达时间}）`。

例如：`9C8569 上海浦东→济州 （07:45-10:05）；9C8568 济州→上海浦东 （21:35-22:15）`。除非用户明确要求，不加日期、“去程/回程”、机场全称或航站楼。

列定义：

| 列 | 字段 |
|---|---|
| A | 编号，游客为连续数字，领队为 TL |
| B | 房号 |
| C | 房型 |
| D | 中文姓名 |
| E | 英文姓名 |
| F | 性别 |
| G | 出生日期 |
| H | 出生地 |
| I | 护照号 |
| J | 签发日期 |
| K | 签发地 |
| L | 护照有效期 |
| M | 联系电话 |
| N | 家庭备注编号 |

## 样式要求

- 用户指定模板优先于内置模板。
- 保留模板的列宽、顶部结构、表头、颜色、边框和合并方式。
- 数据区 A:C 使用模板对应字体；D:M 以模板非空数据单元格为准；N 使用模板备注列字体。
- 内置模板中 D:M 通常为 `Arial Unicode MS` 10 磅，A:C 通常为宋体 11 磅，N 通常为宋体 10 磅。
- H“出生地”和 J“签发日期”必须单独与模板非空示例单元格核对，不能采样空白单元格的默认字体。
- G、J、L 写入真正的日期值，显示格式为 `yyyy/m/d`。
- I 护照号和 M 电话号码按文本处理，禁止科学计数或丢失前导零。
- 数据区设置完整细边框、垂直居中和适当换行。
- 房号和房型按房间纵向合并。
- 备注按同订单家庭纵向合并，不得合并到领队行。
- 数据区必须精确截止到最后一名人员。最后一名人员下一行起，清除内容、合并、边框、填充和其他单元格格式，不得保留模板预设黑线。

## 视觉复核

最终文件必须渲染或在表格应用中打开检查全部已用区域。重点检查：

- 顶部标题没有截断，行程和航班信息完整可见。
- 表头与数据列对齐。
- 中文、英文姓名和证件号码完整显示。
- 日期列字体与模板一致。
- 合并单元格没有覆盖错误人员。
- 有领队时，领队是最后一行且 `TL` 清楚可见；无领队或导游时，不出现 `TL` 行且顶部“领队：”栏仍在。
- 没有残留模板示例人员、空白占位记录或多余旧合并区域。
- 预览范围向人员末行下方额外延伸至少 5 行，确认人员末行即表格末行，下方完全没有黑线或空白表格。
